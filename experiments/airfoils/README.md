# AirfRANS Experiments (Airfoils)

Unified pipeline for training and comparing four neural operators on the
[AirfRANS](https://www.sciencedirect.com/science/article/pii/S0167819122001715)
airfoil dataset: **FNO**, **RNO**, **DNO**, **Geo-FNO**.

## Layout

```
experiments/airfoils/
├── data_prep/              # offline data preparation (run once)
│   ├── index.py            #   COMMON: raw graph -> blocks -> rows (index_raw_data_w)
│   ├── prep_f_r_no.py      #   FNO/RNO: graph -> regular 128x256 grid (fno_data npz)
│   ├── prep_geofno.py      #   Geo-FNO: rows -> unfolded C-grid 137x1128 (.pth)
│   └── prep_dno.py         #   DNO: rows -> zonal resampling -> diffeo -> 256x256 npz

fnofound/
├── models/
│   ├── fno2d.py            # FNO2d (+ padding param covers Geo-FNO)
│   ├── rno.py              # RNO2d (Riesz Neural Operator)
│   ├── dno_airfoil.py      # DNOAirfoil (exact port, checkpoint-compatible)
│   └── dno.py              # DNO (darcy/fluid/reservoir, extended with grid_mesh/mask/padding)
├── layers/spectral_conv.py # shared SpectralConv2d
├── data/data/datasets/airfoil_datasets.py  # 3 loaders + get_airfoil_dataset()
├── data/config/airfoil_config.py          # AirfoilDefault (zencfg)
└── utils/
    ├── losses.py           # FieldLpLoss (train), PerFieldLoss (report)
    └── airfoil_trainer.py  # shared training loop

experiments/scripts/
├── airfoil_train.py        # unified training: --model fno|rno|dno|geofno
└── airfoil_eval.py         # evaluate trained checkpoints, compare on test
```

## Data

Raw AirfRANS graphs live on the external drive:
`/media/expiwt/f2d8c27a-bdac-4400-b1be-cdb75b6b5a40/airfrans/`

Prepared per-method datasets (all generated by `data_prep/`, none committed):

| Method  | Dataset dir                       | Grid        | Size |
|---------|-----------------------------------|-------------|------|
| FNO/RNO | `fno_dataset/fno_data_*.npz`      | 128x256     | 14 GB |
| DNO     | `DNO_data/dno_small/batch_N/*.npz`| 256x256     | 55 GB |
| Geo-FNO | `Geo-FNO_data/batch_N/*.pth`      | 137x1128    | 9.7 GB |
| common  | `index_raw_data_w/batch_N/*.pth`  | rows/blocks | 34 GB |

Global sample index: `((batch - 1) // 4) * 400 + local_number`.
Default split: train 1..800, val 801..900, test 901..1000.

## Data preparation (once)

```bash
python -m experiments.airfoils.data_prep.index \
    --raw_root /media/.../airfrans --out_root /media/.../airfrans/index_raw_data_w

python -m experiments.airfoils.data_prep.prep_f_r_no \
    --raw_root /media/.../airfrans --out_root /media/.../airfrans/fno_dataset

python -m experiments.airfoils.data_prep.prep_geofno \
    --index_root /media/.../index_raw_data_w \
    --graph_root /media/.../airfrans \
    --out_root /media/.../Geo-FNO_data

python -m experiments.airfoils.data_prep.prep_dno --stage a \
    --index_root /media/.../index_raw_data_w \
    --graph_root /media/.../airfrans \

    --dno_root /media/.../DNO_data --out_root /media/.../DNO_data/dno_small
```

All prep scripts are verified to reproduce the existing datasets 1:1.

## Training

```bash
python experiments/scripts/airfoil_train.py --model fno \
    --data.root_dir /media/.../airfrans --opt.n_epochs 300

python experiments/scripts/airfoil_train.py --model dno --opt.n_epochs 300
python experiments/scripts/airfoil_train.py --model geofno  # in=2, padding=8 automatic
python experiments/scripts/airfoil_train.py --model rno --sweep
```

Per-model defaults (registry in `airfoil_train.py`):

| Model  | Class       | Dataset case | in | padding | Notes |
|--------|-------------|--------------|----|---------|-------|
| fno    | FNO2d       | fno          | 3  | 0       | + grid coords |
| rno    | RNO2d       | fno          | 3  | 0       | + grid coords |
| dno    | DNOAirfoil  | dno          | 3  | 0       | + grid_mesh geometry |
| geofno | FNO2d       | geofno       | 2  | 8       | C-grid, no mask |

Loss: `FieldLpLoss` over (vel_x, vel_y, pressure) - nu_t excluded; masked
where the case provides a mask (FNO/RNO/DNO), unmasked for Geo-FNO.

Output per run: `runs_airfoils/<model>_<ts>/{models, logs, plots}`.

## Loading pre-trained models

Checkpoints from the airrans experiments load directly (strict):
FNO (11 runs), RNO (`runs_rno/`), DNO (`runs_dno_small/` + early 8-channel
runs via `use_geom=False`), Geo-FNO (auto key remap `blocks.N.*` -> `spectral_convs.N.*`).

```bash
python experiments/scripts/airfoil_train.py --model dno \
    --model.n_modes 16 --model.hidden_channels 64 \
    --checkpoint /media/.../runs_dno_small/dno_m16_w64_l4_b4/model_best.pth
```

## Evaluation / comparison

```bash
python experiments/scripts/airfoil_eval.py \
    --data.root_dir /media/.../airfrans \
    --out runs_airfoils/leaderboard.json
```

Evaluates all four best checkpoints on the test split (architecture is
inferred from each state dict), prints a per-field rel-L2 table and saves
`leaderboard.json`.
